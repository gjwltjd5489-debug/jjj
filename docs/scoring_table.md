# 매수/매도 100점 점수 기준표 v0 (초기판, QQQ 기준)

> 자의적으로 정한 가중치입니다. 실전 매매용이 아니라 **실험과 검증을 위한 출발점**입니다.
> 실제 데이터로 검토한 결과는 [review.md](review.md)에, 개선한 카드 v1~v4는 [scorecards.md](scorecards.md)에 있습니다.
> 이 표는 `--card v0` 으로 계산되며 비교 기준선으로 남겨 둡니다.

## 1. 구성 요약

| 카테고리 | 만점 | 성격 |
|---|---:|---|
| A. 일목균형표 | 30 | 추세 (구름, 전환/기준선, 후행스팬) |
| B. 이동평균선 | 30 | 추세 (위치, 배열, 기울기) |
| C. 거래량 (VR, OBV) | 20 | VR은 역발상(과열/침체), OBV는 매집 확인 |
| D. 모멘텀 (RSI, MACD) | 20 | RSI는 추세+과열 혼합, MACD는 추세 |
| **합계** | **100** | |

추세 지표(A+B+MACD)가 약 70점, 과열/침체를 보는 역발상 성격 항목(VR, RSI 일부)이 약 25점입니다.
그래서 강한 상승 추세라도 과열이 심하면 점수가 깎이고, 하락 추세라도 투매 구간이면 조금 올라갑니다.

## 2. 신호 구간

| 총점 | 신호 |
|---:|---|
| 80 ~ 100 | 강한 매수 |
| 65 ~ 79 | 매수 |
| 36 ~ 64 | 중립 (보유/관망) |
| 21 ~ 35 | 매도 |
| 0 ~ 20 | 강한 매도 |

**이벤트 신호**
- `BUY`: 총점이 65 이상으로 **올라서는 날**
- `SELL`: 총점이 35 이하로 **내려서는 날**
- BUY와 SELL은 번갈아 나오게 해서 같은 신호가 반복되지 않게 했습니다.

### C. 거래량 (20점)

**VR(Volume Ratio, 20일)**
`VR = (상승일 거래량 합 + 보합일 거래량 합 ÷ 2) ÷ (하락일 거래량 합 + 보합일 거래량 합 ÷ 2) × 100`

| 항목 | 조건 | 점수 |
|---|---|---:|
| C1 VR (14) | VR < 70% (침체권, 역발상 매수) | 14 |
| | 70 ~ 120% | 11 |
| | 120 ~ 200% | 8 |
| | 200 ~ 300% | 5 |
| | 300 ~ 450% | 2 |
| | 450% 이상 (과열권) | 0 |
| C2 OBV (6) | OBV > OBV 20일 이평 (매집 우위) | 6 |
| | 그 외 | 0 |

- VR 구간은 한국 시장에서 흔히 쓰는 해석(70% 이하 바닥권, 450% 이상 과열)을 가져온 것입니다.
  QQQ 같은 대형 ETF는 VR 분포가 다를 수 있으니, `--eval` 출력의 **VR 분포(p5~p95)**를 보고 구간을 보정하세요.
- 거래량 데이터가 없는 종목(지수 등)은 C 카테고리를 빼고 **80점 만점을 100점으로 환산**합니다.

## 4. 계산 조건과 한계

- 200일선과 200일선 기울기 때문에 **약 220거래일 이후부터** 점수가 나옵니다. 넉넉하게 2년 이상 데이터를 넣으세요.
- Investing.com 가격은 **배당 미조정**입니다. 지표 계산에는 큰 문제가 없지만, 수익률 통계에서 배당은 빠집니다.
- 일봉 종가 기준입니다. 신호가 뜬 날 종가에 체결했다고 가정하면 미래 정보를 쓰지 않지만, 실제로는 다음 날 시가 체결이 현실적입니다.
- 가중치와 구간은 과최적화하기 쉽습니다. 구간을 조정할 때는 **기간을 나눠서**(예: 2010~2018 조정 → 2019~ 검증) 확인하세요.

## 5. 다른 종목으로 확장하는 법

1. `scoring/profiles.py`에서 `DEFAULT`를 복사해 새 프로파일을 만듭니다.
   ```python
   SPY = replace(DEFAULT, name="SPY")
   SAMSUNG = replace(DEFAULT, name="005930", ma_short=20, ma_mid=60, ma_long=120,
                     vr_bands=((70, 14), (150, 11), (250, 8), (350, 5), (450, 2), (INF, 0)))
   ```
2. `PROFILES`에 등록하고 `--ticker` 로 지정합니다. 등록하지 않은 이름은 DEFAULT 값으로 계산합니다.
3. 종목마다 바꿀 만한 값
   - 이평 기간: 미국 20/50/200, 한국 20/60/120
   - VR 구간: 종목의 VR 분포에 맞춰 조정 (변동성이 큰 개별주는 VR 범위가 넓음)
   - 신호 임계값: 카드별로 `scoring/cards.py`에 있음 (점수 분포가 종목마다 다르므로 확장 시 확인)
