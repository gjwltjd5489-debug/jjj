# 체크리스트 점수와 매수·매도 규칙

메일의 **성향별 판정**을 그대로 점수로 만들고, 그 점수로 매수·매도 신호를 낸다.

- 코드: `scoring/checklist_score.py` (점수·규칙), `scoring/checklist.py` (메일 표시)
- 검증: `python scripts/eval_checklist_score.py --start 2005-01-01 --split 2018-01-01 --md docs/results/checklist_score_eval.md`
- 검증 원본: [results/checklist_score_eval.md](results/checklist_score_eval.md) (2026-09-30 실행, watchlist 29종목, Yahoo 배당조정 가격)

**바뀐 이력**

| 시기 | 규칙 | 이유 |
|---|---|---|
| 2026-09 초 | 성향 6개 동일 배점, 3일 평균 70 진입 / 40 퇴출 | 메일 색과 신호를 같은 기준으로 (이전에는 v2·v3 점수 카드) |
| 2026-09-30 | **배점 조정(장기 ×2, 모멘텀·거래량 ×0.5)** + **200일선 위에서는 점수로 퇴출하지 않음** | 1년 사후 점검: 상승 추세 속 눌림에서 팔고 더 비싸게 다시 사는 일이 반복 ([signal_review.md](signal_review.md)) |

## 1. 점수 정의

```
점수 = 50 + 50 × Σ(배점 × 색) ÷ Σ(판정 가능한 성향의 배점)
색: 🟢 +1 · 🟠 0 · 🔴 −1 · ⚪ 해당 없음은 분자·분모에서 뺌
```

| 성향 | 배점 | 근거 (2006~2017 데이터, 전 종목 합산) |
|---|---:|---|
| 장기 추세 (200일선·이평 배열) | **×2** | 🟢/🔴에 따라 이후 20일 변동성이 19.7% / 28.1%로 가장 크게 갈림. 색이 바뀌는 횟수는 연 8회로 가장 안정적 |
| 중기 추세 (일목 구름·전환/기준) | ×1 | 20.0% / 26.6%, 연 21회 |
| 추세 강도 (ADX·DMI) | ×1 | 21.4% / 29.9%, 연 11회 |
| 상대강도 (벤치마크 대비) | ×1 | 24.9% / 25.9%. 구분력은 약하지만 종목 선택용으로 유지 |
| 모멘텀 (MACD·RSI) | **×0.5** | 20.3% / 25.0%로 약한데, 연 45회 바뀜 |
| 거래량 (VR·OBV) | **×0.5** | 21.0% / 23.9%로 가장 약하고 이후 수익은 오히려 🔴일 때 높음. 연 39회 바뀜 |

- **배점 기준:** 변동성·하락 위험 구분력과 색이 바뀌는 빈도만 봤다. 매매 성과를 보고 고르지 않았다.
- **검증:** 2018년 이후는 배점을 정할 때 쓰지 않은 구간이다.
- **범위:** 0(전부 🔴) ~ 50(중립) ~ 100(전부 🟢)
- **예시 1:** 장기 🟢에 나머지가 모두 🔴이면 33점이다. 동일 배점일 때는 17점이었다.
- **예시 2:** QQQ가 장기·중기·모멘텀·거래량·상대 🟢, 추세 🟠이면 50 + 50 × 5/6 = **92**점이다.
- **메일 표시:** 성향별 판정 표 머리글에 ×2·×½가 표시돼 있다. 색과 배점만 알면 누구나 같은 점수를 계산할 수 있다.

## 2. 매수·매도 규칙

| 구분 | 조건 |
|---|---|
| 진입 (🟢 매수) | 3일 평균 점수 ≥ 70 **그리고** 종가 > 200일선 **그리고** 과열·고변동 아님 |
| 진입 보류 (⚠️) | 점수는 70 이상인데 200일선 아래이거나 과열(50일선 이격 1년 상위 5%)·고변동(20일 변동성 1년 상위 20%) |
| 퇴출 (🔴 매도) | 3일 평균 점수 ≤ 40 **그리고 종가 < 200일선** |
| 눌림 (🟠, 보유 유지) | 보유 중 3일 평균 ≤ 40인데 200일선 위 → 팔지 않음. 200일선을 깨면 매도 |
| 진입 임박 (🟢) | 대기 중인데 당일 점수가 내일도 같으면 내일 3일 평균 ≥ 70 |
| 청산 임박 (🟠) | 200일선 아래 보유 종목의 3일 평균 ≤ 50, 또는 당일 점수가 내일도 같으면 내일 3일 평균 ≤ 40 |
| 손절 참고가 | 종가 − 2 × ATR(14) |

- **3일 평균을 쓰는 이유:** 하루짜리 흔들림으로 매매가 바뀌지 않게 하려는 것이다.
- **진입 70·퇴출 40으로 간격을 둔 이유:** 기준선 부근에서 사고팔기를 반복하지 않게 하려는 것이다.
- **200일선 위에서 팔지 않는 이유:** 과거 20년 매도 신호의 74%가 200일선 위에서 나왔다.
  - 그 뒤 60일 수익률은 +4.0%로, 아무 날(+3.6%)보다 높았다. 상승 추세 속 매도는 평균적으로 손해였다.
  - 매도한 종목의 78%는 매도가보다 비싸게 다시 샀다.
  - 반대로 200일선 아래 매도 뒤 60일 수익률은 +1.1%로, 실제로 하락을 피했다.

## 3. 검증 (watchlist 29종목, 2006~2026-09)

**조건**
- 신호가 난 날 종가로 판단하고, 다음 날 수익부터 반영한다. 편도 거래비용은 0.05%다.
- 종목마다 지표가 준비된 날부터 계산했다.
- PDBC는 상장 전 구간을 DBC로 이어 붙였다. IBIT는 2025년부터라 기간이 짧다.

## 4. 해석

1. **이전 규칙보다 수익은 늘고, 매매는 절반이 되고, 하락 방어는 약해졌다.**
   - 급락장에서 200일선이 깨질 때까지 기다리므로, 빠른 폭락(2020년)에서는 낙폭이 이전 규칙의 약 2배다.
   - 그래도 계속 보유의 절반 이하다.
2. **"하락 위험을 줄이는 도구"라는 성격은 그대로다.**
   - 계속 보유보다 연수익은 낮다(8.5% vs 6.9%). 대신 최대낙폭이 −59%에서 −34%로 줄었다.
   - 점수는 여전히 수익을 예측하지 못한다.
3. **메일에서 "🟠 눌림 (보유 유지)"가 보이면** 점수는 퇴출선 아래지만 장기 추세가 살아 있는 상태다. 200일선이 깨지면 그날 매도 신호가 난다. 장초반 메일은 200일선 2% 안으로 다가오면 알린다.
