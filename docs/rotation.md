# v5 조합 카드 + 저상관 바스켓 상위 n 로테이션

## 요약
- **v5 조합 카드**: v3 눌림목 신호로 진입하고, v2 추세 점수가 40 이하로 떨어지면 청산한다. 순위용 100점 = 보유 자격 50 + v2 추세 점수의 절반.
- **바스켓**(상관 낮은 6개): **QQQ · VWO · GLD · PDBC · EDV · UUP**.
  - VTV는 QQQ와 겹쳐서 뺐다.
  - 달러(UUP)를 추가했다. 다른 자산이 함께 빠지는 국면에서 추세가 나는 자산이기 때문이다.
- **전략**: 보유 자격이 있는 종목 중 v5 점수 상위 n개를 동일가중으로 보유한다. 빈자리는 현금이다.
- **검증 결과(대용 데이터, 아래 한계 참고)**
  - v5 로테이션은 동일가중 보유보다 **최대낙폭을 줄였다**(−27% vs −40%).
  - 하지만 **수익률은 절반 수준**이었고(연 4.2% vs 7.7%), **v2 단독 로테이션보다도 못했다**(7.8%).
  - 이유: 눌림을 기다리다 눌림 없는 추세를 놓쳤다(현금 비중 24%).
- 실제 ETF 데이터로는 이 개발 환경의 네트워크 차단 때문에 아직 돌리지 못했다. 인터넷이 되는 곳에서 명령 한 줄로 돌릴 수 있다([실행](#실제-etf로-실행)).

## 1. v5 조합 카드

| 구분 | 규칙 |
|---|---|
| 진입 | 대기 중에 **v3 점수가 65를 상향 돌파**하고, 그날 v2 점수가 40 초과 |
| 청산 | 보유 중에 **v2 점수(3일 평활)가 40 이하** |
| 점수 | 보유 자격 50점 + v2 점수 ÷ 2 (0~50) → 보유 자격 있는 종목은 항상 50점 이상 |
| 신호 | 강한 매수 ≥90(보유 & v2≥80) · 매수 ≥50(보유) · 중립(대기) · 매도 ≤20(대기 & v2≤40) · 강한 매도 ≤12.5 |

- 각 카드 자체의 BUY/SELL 교대 규칙과 상관없이 **점수 수준**으로 판단한다.
  - 예: v2가 이미 SELL을 냈더라도, 재진입 뒤 다시 40 아래로 가면 청산된다.
- `--rank v2v3`로 바꾸면 점수 = 50 + (v2 + v3) ÷ 4가 된다(눌림 깊이도 순위에 반영).
- **v6(사후 아이디어)**: v5와 같되, **v2 점수가 70을 상향 돌파할 때도 진입**한다. v5 결과를 보고 만든 것이라 비교용으로만 둔다.

코드: `scoring/cards.py`(`Combo`), `scoring/score.py`(`combine`). 단일 종목은 `run_score.py ... --card v5`로 본다.

## 2. 종목 선정

### 원칙
상위 n 로테이션에서 바스켓이 제 역할을 하려면 **"서로 다른 시기에 추세가 나는 자산"**이 필요하다. 두 가지 상관을 같이 본다.
- **수익률 상관**(주간): 같이 오르내리는가. 해외 자산의 거래시간 차이 때문에 일간 대신 주간을 쓴다.
- **점수 상관**(v2 추세 점수): 보유 자격이 같은 날 함께 생기고 사라지는가. 사용자가 말한 "지표 간 상관"이다.

`select_low_corr`는 두 상관의 평균을 기준으로, 이미 고른 종목들과 평균 상관이 가장 낮은 후보를 하나씩 추가한다(탐욕법).

### 제시 종목 평가 (대략적인 장기 경향 — 실제 값은 스크립트 출력으로 확인)
| | QQQ | VTV | VWO | GLD | PDBC | EDV |
|---|---|---|---|---|---|---|
| QQQ | – | **높음** | 높음~중간 | 낮음 | 중간 | 낮음~음(−) |
| VTV | | – | 높음 | 낮음 | 중간 | 낮음~음(−) |
| VWO | | | – | 낮음~중간 | 중간 | 낮음 |
| GLD | | | | – | 중간 | 낮음~중간 |
| PDBC | | | | | – | 음(−) 경향 |

- 주식끼리(QQQ·VTV·VWO)는 서로 상관이 높다. 셋 다 넣으면 상위 n 자리를 같은 "주식 위험"이 채운다.
- 채권(EDV)은 주식과 음(−)의 상관인 시기가 많았다. 다만 2022년처럼 함께 빠지는 해도 있다. 이런 때는 v2 청산이 방어해야 한다.
- 금(GLD)과 원자재(PDBC)는 주식과 상관이 낮다. 서로는 중간 정도다.

### 선정 결과
| 종목 | 역할 | 선정 이유 |
|---|---|---|
| QQQ | 미국 성장주 | 기준 자산 |
| VWO | 신흥국 주식 | QQQ와 상관은 높은 편이다. 하지만 주도 국면이 달랐다(2003~07·2009~10 신흥국 우위, 2011~21 미국 우위). 로테이션에서는 추세가 나는 **시기**가 다르면 쓸모가 있다 |
| GLD | 금 | 주식과 저상관, 통화가치 하락·위기 헤지 |
| PDBC | 원자재 | 인플레이션 국면. 2014-11 상장 전은 **DBC**(같은 지수 계열) 수익률로 이어 붙인다 |
| EDV | 초장기 국채 | 디플레·침체 국면, 주식과 음(−)상관 경향. 듀레이션 약 24로 추세가 크게 난다 |
| UUP | 미 달러 | **추가**. 2008·2014~15·2022처럼 위험자산·금·원자재가 함께 약할 때 강세를 보인다 |
| ~~VTV~~ | 미국 가치주 | **제외**. QQQ와 같은 미국 대형주 위험이다 |

- 상관 기준만 엄격하게 적용하면 VWO도 후순위가 될 수 있다. 실제 데이터로 `--select-from`을 돌려 확인할 것.
- 더 넓은 후보는 `scoring/basket.py`의 `CANDIDATES`에 있다: TLT, IEF, TIP, EFA, VNQ, DBMF 등.
- 공통 기간은 UUP(2007-02)와 EDV(2007-12) 상장 뒤부터다. 지표 준비 기간(약 280거래일)을 빼면 **백테스트는 2009년 무렵부터** 가능하다.

## 3. 로테이션 규칙 (`scoring/portfolio.py`)
1. 매일 종가로 판단하고 다음 날 수익부터 반영한다.
2. 보유 중인 종목이 자격을 잃으면(v2 ≤ 40) **즉시 매도**하고 그 자리는 현금으로 둔다.
3. 빈자리는 **매일** 채운다. 자격이 있는 종목 중 점수가 높은 순이다(v3 진입 타이밍을 살리기 위해).
4. **교체**는 리밸런스 날(기본 5거래일마다)에만 한다. 보유 종목이 순위 n+1 밖으로 밀리면 교체한다(`--buffer 1`).
5. 자리마다 1/n 비중이다. 비용은 비중 변화 1당 0.1%다. 현금은 단기국채 수익률(`--cash`)을 받는다.

### 해석
1. **분산 효과가 가장 컸다.**
   - 상관 낮은 3개 동일가중만으로도 MDD가 −80%(나스닥, 원유)에서 −40%로 줄었고, 샤프는 0.54였다.
   - 로테이션은 MDD를 −25~27%까지 더 줄였다.
2. **v5의 약점은 진입이다.**
   - v3 BUY는 "상승 국면 + 눌림"이 겹쳐야 나온다.
   - 눌림 없이 오르는 추세는 놓쳤다. 2009~2010 주식 반등, 2011 채권 랠리(v2 단독 +14%, v5 −7.5%)가 그 예다.
   - 그래서 현금이 24%나 됐다.
3. **청산은 v2와 같으므로 방어력은 비슷했다.** 줄어든 것은 수익뿐이다. 2008년에도 +23%(v2 단독 +26%)였다.
4. 추세 확인 진입을 더한 v6가 v5보다 나았지만, v2 단독보다는 못했다. **이 표본에서는 눌림목 진입이 가치를 더하지 못했다.**
5. 상위 n이 클수록 변동성과 MDD는 줄지만 현금이 늘어 수익도 준다. 3개 바스켓이라 선택 효과는 제한적이다.

### 한계
- 대용 3종목, 2000~2017이다. 채권은 금리가 20년간 떨어진 대세 상승기라 유리한 표본이다.
- 금(GLD), 신흥국(VWO), 달러(UUP) 대용 데이터는 없었다.
- 원유 현물은 PDBC와 다르다(롤 수익, 에너지 외 품목).
- 대용 채권 지수는 금리로 계산한 근사치다.
- v6와 순위 방식 비교는 결과를 본 뒤 추가한 것이다. 이 결과로 규칙을 고르면 과최적화다. **실제 ETF, 특히 2019년 이후 구간에서 다시 확인해야 한다.**

## 실제 ETF로 실행
```bash
pip install finance-datareader

# 기본 바스켓 (QQQ VWO GLD PDBC(+DBC) EDV UUP), 상위 2개, 현금 = BIL
python scripts/rotate_basket.py --top 2 --cash fdr:BIL --md out/rotation.md

# 후보에서 상관 낮은 6개 자동 선정 (QQQ 포함)
python scripts/rotate_basket.py --select-from QQQ VTV VWO EFA GLD PDBC EDV TLT TIP UUP VNQ --k 6 --must QQQ --cash fdr:BIL

# Investing.com CSV로 (data/QQQ.csv ...). 배당 미조정이라 EDV·VWO 수익이 연 3~4% 과소평가된다
python scripts/rotate_basket.py --source "data/{t}.csv"
```

출력 내용
1. 두 가지 상관행렬(수익률, v2 점수)과 선정 결과
2. 오늘 기준 종목별 v2·v3·보유 자격·v5 점수
3. 백테스트 표: v5 상위 1~3, v6, v2 단독, 동일가중, 개별 보유
4. 연도별 수익률, 종목별 보유 비중, **현재 보유안**, 최근 매매

데이터 주의
- `fdr:`(Yahoo)는 배당 조정 가격(Adj Close)으로 시가·고가·저가·종가를 모두 조정해 쓴다.
- EDV(연 3~4%)와 VWO(연 3%)는 분배금 비중이 커서 **조정 가격이 꼭 필요**하다.
