# 체크리스트 점수와 매수·매도 규칙

메일의 **성향별 판정**을 그대로 점수로 만들고, 그 점수로 매수·매도 신호를 낸다.

**바꾼 이유**
- 이전 신호는 체크리스트 v2 이전에 만든 v2·v3 점수 카드(v6 조합 규칙)를 썼다.
- 그래서 메일의 색과 추천이 서로 다른 기준에서 나왔다.
- 이제는 표의 색에서 점수가 나오고, 그 점수로 신호를 판단한다.

- 코드: `scoring/checklist_score.py` (점수·규칙), `scoring/checklist.py` (메일 표시)
- 검증: `python scripts/eval_checklist_score.py --start 2005-01-01 --split 2018-01-01`
- 검증 원본: [results/checklist_score_eval.md](results/checklist_score_eval.md) (2026-09-29 실행, Yahoo 배당조정 가격)

## 1. 점수 정의

```
점수 = 50 + 50 × (🟢 성향 수 − 🔴 성향 수) ÷ 판정 가능한 방향 성향 수
```

- **방향 성향 6개:** 장기 추세 · 중기 추세 · 모멘텀 · 추세 강도 · 거래량 · 상대강도
- **계산 방법:** 🟢 +1, 🟠(혼조·횡보·약함) 0, 🔴 −1이다. ⚪(해당 없음, 예: 금·채권의 상대강도)은 분모에서 뺀다.
- **변동성·과열**은 방향이 아니라 위험 표시라 점수에 넣지 않는다. 대신 진입을 막는 조건으로 쓴다.
- **범위:** 0(전부 🔴) ~ 50(중립) ~ 100(전부 🟢). 성향 6개가 판정 가능하면 점수는 8.3점 단위로 움직인다.
- **예시:** QQQ가 🟢4 🟠2 🔴0이면 50 + 50 × 4/6 = **83**. 메일 표의 색만 세면 누구나 같은 점수를 얻는다.

## 2. 매수·매도 규칙

결과를 보고 맞춘 값이 아니라 **먼저 정한 값**이다.

| 구분 | 조건 |
|---|---|
| 진입 (🟢 매수) | 3일 평균 점수 ≥ 70 **그리고** 종가 > 200일선 **그리고** 과열·고변동 아님 |
| 진입 보류 (⚠️) | 점수는 70 이상인데 200일선 아래이거나 과열(50일선 이격 1년 상위 5%)·고변동(20일 변동성 1년 상위 20%) |
| 퇴출 (🔴 매도) | 3일 평균 점수 ≤ 40 |
| 진입 임박 (🟢) | 대기 중인데 당일 점수가 내일도 같으면 내일 3일 평균 ≥ 70 |
| 청산 임박 (🟠) | 규칙상 보유 구간인데 3일 평균 점수 ≤ 50, 또는 당일 점수가 내일도 같으면 내일 3일 평균 ≤ 40 |
| 손절 참고가 | 종가 − 2 × ATR(14) |

- **3일 평균을 쓰는 이유:** OBV·VR·MACD처럼 하루 만에 뒤집히는 항목이 있어서, 하루짜리 흔들림으로 매매가 바뀌지 않게 하려는 것이다.
- **진입과 퇴출 기준이 다른 이유:** 진입은 70, 퇴출은 40으로 간격을 둬서, 기준선 부근에서 사고팔기를 반복하지 않게 했다.

## 3. 검증 (watchlist 27종목, 2006~2026-09)

조건
- 신호가 난 날 종가로 판단하고, 다음 날 수익부터 반영한다. 편도 거래비용은 0.05%다.
- 종목마다 지표가 준비된 날부터 계산했다. PDBC는 상장 전 구간을 DBC로 이어 붙였다. IBIT는 2025년부터라 기간이 짧다.

## 4. 해석

1. **메일과 추천이 같은 기준을 쓴다.** 표의 색이 점수가 되고, 점수가 신호가 된다.
   - 예: META는 🟢6개로 100점이지만 표에서 🟠과열·🟠고변동이라 "진입 보류"로 나온다.
2. **이전 규칙(v6)보다 하락 방어는 강하고 수익은 조금 낮다.**
   - 보유 기간이 절반 정도(47%)라 수익을 더 포기한다. 대신 최대낙폭이 더 작다.
   - 위험 대비 수익은 전체 기간으로는 비슷하다. 2006~2017에는 v6가, 2018~2026에는 새 규칙이 앞섰다.
3. **매매가 더 잦다.** 종목당 연 2.7회로, v6(1.0회)보다 많다. 27종목 전체로 보면 한 주에 신호 1~2건 정도다.
4. **예측 도구가 아니다.** 점수는 현재 추세 상태를 요약할 뿐이다. 점수가 낮은 구간에서는 변동성과 급락 위험이 뚜렷하게 컸다.
